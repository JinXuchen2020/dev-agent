# 阶段四：前沿特性与收尾

> 学习目标：锦上添花——代码沙箱闭环、性能压测达标、BDD 全量覆盖、简历作品集包装。

## 学习目标

- [ ] **Docker.DotNet**：.NET 操作 Docker 容器、镜像、网络的核心 API
- [ ] **代码沙箱安全**：容器隔离、资源限制、网络白名单、执行超时的实际配置
- [ ] **SerpAPI / Google Search**：SK 集成外部 API 实现多步调研链
- [ ] **性能调优**：从 30s 优化到 10s 的实战经验（缓存、并行、模型选择）
- [ ] **BDD 全量覆盖**：为历史代码补验收场景的策略和优先级
- [ ] **简历作品集包装**：如何将工程化项目转化为面试素材

## 前置依赖

- [ ] 阶段三已完成并提交
- [ ] 阶段三的性能基准已跑通（P95 < 30s）
- [ ] Docker Desktop 可正常操作容器（`docker ps` 无报错）

## 任务清单

- [ ] **Code Agent 闭环**：Docker.DotNet 操作沙箱，生成-运行-调试-修复闭环（**知识点**：Docker SDK + 安全配置）
- [ ] **Research Agent**：SK 集成 SerpAPI，实现多步调研（**知识点**：外部 API 集成 + 链式调用）
- [ ] **性能压测与优化**：达到 P0 目标（并发 5 工作流、步骤 P95 < 10s、模型调用 P95 < 15s）
- [ ] 补全 BDD 全量验收用例，接入 CI/CD（**知识点**：测试分层 + CI 集成）
- [ ] 整理文档与简历作品集描述（**知识点**：技术影响力包装）

## 验收标准

1. Code Agent 能生成代码 → 运行 → 发现错误 → 修复 → 重新运行，形成闭环
2. Research Agent 能接收一个开放问题 → 多步搜索 → 输出结构化报告
3. 性能达到 P0 目标（8.6 全部 7 项指标）
4. 所有关键路径都有 BDD 验收场景覆盖
5. 简历中有一段 200 字的技术描述，突出 .NET 工程化 + AI 融合
