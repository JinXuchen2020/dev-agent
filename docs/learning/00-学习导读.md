## 0.2 复盘自测汇总（合上文档能答 = 真懂）

- **01 DDD**：聚合根为什么用 `private set`？值对象为什么用 `record`？领域事件为什么不直接 `mediator.Publish`？
- **02 架构**：Domain 为什么零 PackageReference？Application 为什么不能引用 Infrastructure？接口该定义在哪一层？
- **03 MediatR**：`ICommand<T>` 标记接口解决什么问题？Query 为什么不触发 `SaveChanges`？
- **04 EF**：只读集合为什么要 `UsePropertyAccessMode(Field)`？`OwnsMany` 的影子主键为什么必须 `ValueGeneratedOnAdd()`？值对象列名冲突怎么解决？
- **05 测试**：为什么架构测试要放在金字塔最底层？BDD 不解决哪类问题？
- **06 踩坑**：编译错、运行炸、数据写不进、并发不准、环境不对，分别先查什么？（口诀见该章末尾）
- **07 演进**：为什么 Phase 1 全用 Stub？Phase 3 才做前端的原因？
- **08 决策**：模型路由为什么选 Flat Priority List？Domain 事件为什么用适配器而非直接 MediatR？
- **09 Phase4**：fail-loud 为什么优于 fail-silent？分页为什么必须在数据库端做？token 为什么不等于字符？
- **10 Phase5**：多方案认证为什么用 policy scheme？多租户为什么"只建 DB Query Filter"不够？`no such table` 但模型有该实体，根因通常是什么？

## 0.3 怎么用这套笔记复盘

1. 接到任务 → 先用 §0.1 表定位要看的章节。
2. 读时重点看每个「问题 → 解法 → 代码落点」。
3. 读完合上文档，用 §0.2 对应章的 3 问自测；答不出就回看。
4. 报错时优先翻 `06-common-pitfalls.md` 的「按症状查因」表（最前那张），秒定位坑号；随身速记看 `cheatsheet-复盘速记.md`。
