# Templates

本文件由 codebase-optimizer Skill 在需要生成状态文件/报告/任务清单/最终总结时加载。模板中的 `{占位符}` 表示需要 Agent 动态填充的内容。

## status.md 模板

```markdown
# Codebase Optimizer Status

## 项目信息
- **项目路径**: {workspace_root}
- **编程语言**: {检测到的主要语言}
- **框架**: {检测到的框架}
- **总代码行数**: {粗略统计}

## 阶段配置
- **阶段1（基础质量）**: 架构 → 代码质量 → 正确性 → 测试
- **阶段2（进阶质量）**: 性能 → 安全 → 工程化 → 桩代码替换进度 → 生产就绪度

## 累计统计
- **总发现问题**: N | **已修复**: N | **修复率**: XX%

## 当前状态
- **当前阶段**: 阶段1
- **当前轮次**: Round 0
- **当前步骤**: initialized
- **运行模式**: {交互/自动化}
- **阶段1状态**: 🔄 进行中
- **阶段2状态**: ⏳ 待开始
- **启动时间**: {当前日期}
- **上次更新**: {当前日期}

## 轮次记录
| 轮次 | 阶段 | 发现问题 | 已修复 | 状态 |
|------|------|----------|--------|------|
```

**current_step 取值**: `initialized` / `analyzing` / `task_generated` / `executing_R{N}-T{X}` / `all_tasks_done` / `evaluating` / `phase_complete` / `done`
